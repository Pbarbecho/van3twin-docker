2.1 · Descargar traci.py

El script vive en el repositorio del curso; se descarga a results/ para que el contenedor lo vea.
08 / 12RVH · Validación del entorno
# En su PC, desde la carpeta del proyecto (van3twin-docker)
mkdir -p results/traci
curl -L -o results/traci/traci.py \
  https://raw.githubusercontent.com/Pbarbecho/van3twin-docker/main/results/traci/traci.py

# Si ya tiene el repo clonado, basta con actualizarlo
git pull origin main
ls results/traci/traci.py                       # ← debe existir
Dónde quedaEn su PC: results/traci/traci.py.
En el contenedor: ~/results/traci/traci.py (mismo archivo, por el bind mount).
docker compose exec van3twin ls ~/results/traci/
Qué hace el script
  • Prueba los puertos 3400–3410 hasta encontrar SUMO
  • Declara traci.setOrder(3) antes del primer paso
  • En cada iteración pide simulationStep(t + 0.5)
  • Imprime id, posición y velocidad de cada vehículo
  • Cierra con traci.close() al terminar
No necesita instalar nada: el contenedor ya trae SUMO 1.12 con su librería traci y SUMO_HOME=/usr/share/sumo. El script se ejecuta dentro del contenedor.
