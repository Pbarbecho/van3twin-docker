# Validación del entorno de simulación — deck web

Presentación HTML (1920×1080) para la sesión de validación de RVH:
1. Cambio de mapa (Cuenca) en `docker-compose.yml` + `results/cuenca/`, simulación con el visor web (2 clientes TraCI).
2. Descarga y ejecución de `results/traci/traci.py` (3 clientes TraCI).
3. Reto: modificar `traci.py` para volcar id, tipo, velocidad y posición a un CSV.

Abrir `index.html` en el navegador (vista general → clic en una lámina → Presentar).
Teclas: ← → pasos y páginas · Esc vista general · F pantalla completa · + − 0 zoom.
